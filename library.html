数据范围与评分规则

这里是本机缓存评分库，不是 Netflix 全量目录。关闭 Netflix 后仍可查看；打开本页不会向评分网站发起查询。缓存最多保留 600 个查询版本，清缓存、切换取分模式或更换 Key 会清空这里的记录，之后浏览 Netflix 时重新积累。

不填 Key：Cinemeta 提供 IMDb 镜像，剧集可另有 TVmaze 独立评分。有 Key 且启用 OMDb：补充 IMDb、烂番茄与 Metacritic；OMDb 失败保留免费源结果。不是每部作品都有全部评分。

自动口径依次选择 IMDb → TVmaze → 烂番茄 → Metacritic，不取最高分、不求平均。缺失或未确认评分不算 0 分；评分段在自动口径下换算为 10 分制。本页筛选不改变 Netflix 遮罩设置。

当前“类别”指电影 / 剧集；资料包括匹配标题、年份、匹配依据、来源与查询时间。作品是否仍在你所在地区的 Netflix 提供，请打开 Netflix 核对。
