在 Netflix 浏览作品时，让评分直接出现在卡片和悬浮放大预览中；按自己选择的评分来源与阈值，弱化低分内容。

数据去向：为匹配评分，插件会把遇到的片名或 IMDb ID 直接发给 Cinemeta、IMDb、TVmaze；按需补充英文名时会匿名请求对应 Netflix 公开标题页，可选 Key 仅发给 OMDb。遇到的卡片也可能来自「继续观看」「我的片单」等个性化行，相关作品和查询时间会保存在本机缓存；这不是观看历史的完整导出。第三方可看到正常连接信息（如来源 IP），项目没有自己的收集服务器。详见隐私政策。

主要功能
• 卡片评分角标：来源分别标注，不把不同网站的评分混成平均分。
• 低分遮罩：阈值和遮罩深度可调，悬停时可恢复亮度；无评分或未确认的作品不会被当成低分。
• 放大预览：复用同一作品的评分，切换作品时防止旧分数残留。
• 匹配纠错：结合标题、年份和类型匹配；不确定的结果可手动选择，之后也可恢复自动匹配。
• 本机评分库：浏览本机已缓存的作品，支持搜索、电影/剧集和状态筛选、排序、分组及来源详情。打开评分库本身不发起评分查询。
• 中英文界面：按浏览器语言默认选择，也可手动切换。

评分来源与限制
不填写 API Key 也可使用当前免费来源：Cinemeta 提供的 IMDb 镜像评分，以及剧集的独立 TVmaze 评分。IMDb 镜像可能滞后，不是 IMDb 官方 API。可选填写自己的 OMDb Key，补充 IMDb、烂番茄及 Metacritic 数据；受作品覆盖、配额和服务可用性影响，不保证每部作品都有全部评分。

使用前请了解
Netflix 卡片功能需要你能正常登录并使用 Netflix 网站；本插件不提供 Netflix 会员或观看权限，也不绕过地区限制。它不是全量影视目录或永久收藏夹：清缓存、改变评分提供方设置和缓存淘汰会影响评分库记录。

数据与隐私
插件没有广告、分析 SDK 或项目自建收集服务器，但不是完全离线工具：匹配时会将片名或 IMDb ID 发给相关评分服务；弱匹配时可能匿名请求同一 Netflix ID 的公开英文标题页。可选 Key 仅发送给 OMDb。设置、匹配缓存、手动绑定和可选 Key 保存在本机。详情及当前存储安全限制见隐私政策。

权限用途
storage 用于本机设置、缓存、手动绑定和可选 Key；当前候选的 activeTab 用于用户打开弹窗时识别当前标签页状态；Netflix 及上述评分服务的站点权限用于卡片展示、匹配和评分请求。没有全浏览器历史读取权限、广告或分析 SDK。

这是独立开源项目，与 Netflix、IMDb、TVmaze、OMDb 或其他评分服务无隶属、赞助或官方认可关系。第三方数据及商标权利归各自所有者。
