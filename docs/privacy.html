Netflix Score Lens — Privacy Policy

Effective: October 19, 2026. Maintainer: cyhhao. Applies to the publicly released extension code, currently distributed for manual installation.

Purpose

This independent extension matches Netflix titles with rating services, displays labelled scores, dims low-rated titles, and lets you browse locally cached matching results. It is not affiliated with Netflix or the rating providers.

Information handled on your device

  • Titles, Netflix title IDs, available year and movie/series type from Netflix cards you encounter. It may access public metadata for those requested IDs to improve matching.
  • Matching results, IMDb IDs, scores, source links, timestamps and your manual match choices.
  • Your settings and local library search/filter preferences.
  • An optional OMDb API key that you explicitly supply. No key is bundled.
  • The current tab URL, when you open the popup and grant activeTab, to show whether the page is Netflix, another site, or a browser-restricted page. It is not sent to a project backend.

The extension does not read Netflix passwords, authentication cookies, account profiles or the browser's full history. It does not intentionally collect messages, payment details, health information or location coordinates.

Requests to third parties

Titles and identifiers are sent to rating services; this is not an entirely offline tool. When an automatic title search cannot be confidently confirmed (including ambiguous or missing English-language results), the extension also requests the matching public Netflix title page with the Netflix ID, an English Accept-Language header and omitted credentials. It does not intentionally attach Netflix cookies, execute page scripts or store the returned HTML. As with HTTPS requests generally, a receiving service can see the source IP and normal connection/request metadata. Only information needed for the displayed rating/matching functionality is sent.

These third parties operate independently and may retain request logs according to their policies; the maintainer does not control or promise deletion of those logs.

No project collection server

The extension has no project-operated collection backend, analytics SDK, ads, tracking pixels, sale of data or paid profiling. The maintainer does not receive your key or cached titles through the extension. If you choose to open a GitHub Issue, GitHub receives what you submit; never include secrets, browser profiles or private viewing information there.

Storage, retention and deletion

Chrome extension local storage holds settings, optional credentials, manual bindings, up to 600 cached rating-query variants and a separate cache of up to 600 requested Netflix title lookups. Normal successful scores and verified English display titles are reusable for up to seven days; unavailable title-page results are reusable for ten minutes and title-request errors for one minute. Optional title-page failures do not shorten successful rating reuse or trigger repeated rating-provider lookups. Warning/error/unmatched rating results have shorter reuse intervals. Expiry means “refresh on a later lookup,” not guaranteed deletion after the TTL. Entries can remain until eviction, clearing or uninstall. Changing the key or provider mode resets both caches. Library filters use local extension-page storage.

  • Use “clear cache” to remove cached Netflix title aliases as well as cached ratings. If the extension remains enabled on Netflix, encountered titles can be added again.
  • Use the explicit remove-key action to delete the saved OMDb key. Pause the extension to stop new automatic queued requests; already-issued requests may finish.
  • Clear-cache intentionally retains settings and manual bindings. Uninstalling the extension removes its extension storage, including those records and local library view preferences.
Security limit: storage is restricted to trusted extension contexts, and requests use HTTPS, but the current build does not implement application-level encryption at rest for the key or title cache. It is not a password vault and does not protect against access to your local browser profile or a compromised device. This limitation is an open pre-store-release security item, not a claim of compliance with every Chrome Web Store requirement.

Use limitations

Data is used only for the extension's disclosed matching, scoring, local library and settings features. It is not used or transferred for advertising, creditworthiness, lending, generalized market research or unrelated profiling. No human review of your local records is part of the extension. This describes actual behavior; formal Chrome Web Store Limited Use/security certification will be completed only after the release's open policy checks are resolved.

Changes and contact

Policy changes will be versioned in the public repository alongside behavior changes. For non-sensitive questions, use project Issues. For vulnerabilities, use GitHub private security reporting and the security policy. Do not post credentials publicly.

插件在本机保存设置、已遇到作品的匹配/评分缓存及可选 OMDb Key；为匹配取分，会将片名或 IMDb ID 发给上述第三方服务；需要跨语言核对时，还会以不带 Cookie 的匿名请求把 Netflix 作品 ID 发给 Netflix 公开标题页。服务可看到来源 IP。项目没有自有收集服务器、分析 SDK 或广告，不读取 Netflix 密码、Cookie 或浏览器完整历史，不保存标题页 HTML。本机保存不等于加密；当前版本未实现 Key/缓存的应用层静态加密。可清缓存、移除 Key、暂停或卸载；过期缓存并不自动删除，清缓存也不会删除手动绑定。
